# Capy-barangolás
A projekt célja egy 2D oldalnézetes platformer játék fejlesztése Unity környezetben.  
A játék főhőse egy kapibara, amelynek célja, hogy különböző pályákon keresztül összegyűjtse a szétszóródott kicsinyeit, miközben akadályokat kerül ki és ellenségekkel küzd meg.
